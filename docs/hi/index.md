## अक्सर पूछे जाने वाले सवाल

::: details क्या सब कुछ वाकई मुफ़्त है?
हाँ। टूल्स और गाइड इस्तेमाल के लिए मुफ़्त हैं — टूल्स के लिए किसी अकाउंट की ज़रूरत नहीं है, और डॉक्स पढ़ने के लिए कुछ खरीदना नहीं पड़ता।
:::

::: details क्या मुझे अकाउंट चाहिए?
नहीं। टूल्स और गाइड के लिए किसी अकाउंट की ज़रूरत नहीं है।
:::

::: details मेरा डेटा कहाँ प्रोसेस होता है?
आपके डिवाइस पर। टूल्स पूरी तरह आपके ब्राउज़र में चलते हैं — आपकी फ़ाइलें कभी अपलोड नहीं होतीं।
:::

::: details क्या Hindi वर्शन है?
हाँ। हर गाइड /hi/ के तहत Hindi में उपलब्ध है — वही पेज, वही कंटेंट।
:::

::: details मैं डॉक सुझाना या गलती बताना चाहूँ तो?
GitHub पर issue खोलें: [dusrel-docs issues](https://github.com/dusmamud/dusrel-docs/issues)।
:::
