## FAQ

::: details Is everything really free?
Yes. The tools and guides are free to use — no account is needed for the tools, and there is nothing to buy to read the docs.
:::

::: details Do I need an account?
No. The tools and guides need no account.
:::

::: details Where is my data processed?
On your device. The tools run entirely in your browser — your files are never uploaded.
:::

::: details Is there a Hindi version?
Yes. Every guide is available in Hindi under [/hi/](/hi/) — same pages, same content.
:::

::: details How do I suggest a doc or report a mistake?
Open an issue on GitHub: [dusrel-docs issues](https://github.com/dusmamud/dusrel-docs/issues).
:::
